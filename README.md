# 城市纯玩企划 / 静态互动网页

入口为 `index.html`，无需构建，也不依赖外部 CDN。Three.js 运行文件保存在 `vendor/`，全部图片素材和已子集化的小赖字体保存在 `assets/`。

本地预览：在此目录执行 `python3 -m http.server 4176 --bind 127.0.0.1`，再打开 http://127.0.0.1:4176/ 。浏览器需要 WebGL。

主要体验：三渲二立体书、弯曲纸面翻页、点击/划动/方向键操作、桌面透视跟随、三个预设城市场景、本地照片画框、城市限定书创建、书架陈列和当前画面 PNG 保存。自定义城市、页数与照片只保存在当前浏览器，不上传服务器。

辅助参数：`?art=1` 隐藏界面用于场景审阅，`?studio=1` 显示辅助导出按钮。
